# Prismaflow

# Do - Don't

1. **Always** when you do a change look .agents/skills/* and stay updated for project changes.
2. **Always** write the code, comments and ui texts in english.
3. **Always** ask before adding a new package
4. **Always** use pnpm and ts for development

5. **Never** make a change in database or project settings instead of it, add a new markdown document in .agents/changes/ explaining what do i do.
6. **Never** Edit /dev or /public folder.
7. **Never** make a new constant type without adding it in src/types

# Recomendations

1. If you can't solve the problem, stop of thinking and add a new markdown document explaining the problem in .agents/problems/
2. When you need to add a new .env variable add it in example.env
