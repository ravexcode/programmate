## 🎟️ TICKET: Create To Do List section logic

**ID:** FE-004  
**Tipo:** Feature
**Prioridad:** Alta

**Descripción:**
Implementar la lógica para la sección de Lista de Tareas en la aplicación. Esto incluye crear funciones para agregar, editar y eliminar tareas, así como marcar tareas como completadas.

**Alcance:**

* Crear una función para agregar tareas a la lista.
* Implementar la funcionalidad para editar tareas existentes.
* Permitir eliminar tareas de la lista.
* Agregar la opción de marcar tareas como completadas.

**Criterios de aceptación:**

* [ ] El usuario puede agregar una nueva tarea a la lista.
* [ ] El usuario puede editar el texto de una tarea existente.
* [ ] El usuario puede eliminar una tarea de la lista.
* [ ] El usuario puede marcar una tarea como completada.

**Notas técnicas:**

- Utilizar React para manejar el estado de la lista de tareas.
- Almacenar las tareas en el estado del componente o utilizar un estado global si es necesario.
- Asegurarse de que la interfaz de usuario se actualice correctamente al agregar, editar, eliminar o marcar tareas como completadas.
