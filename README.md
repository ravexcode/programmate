# Get started about our project
1. **Languajes used:**
  - Docker
  - TypeScript

2. **Framework used:** NextJS
3. **Architecture:** Screamming architecture
4. **Node compiler** pnpm
5. **Images types**
  - Logos: _SVG_
  - Images: _WEBP_

# Building in locale
``` bash
pnpm docker-build
pnpm docker-run
```
> To know about the dockers running type in the bash: **pnpm what-docker**.

> To kill the docker type: **pnpm docker-kill**.
